Ce dossier doit contenir les deux logos utilises sur la page de garde du rapport :

  1) le logo BIAT IT, enregistre sous le nom :
       biat-it-logo.png   (ou .jpg / .jpeg / .pdf)

  2) le logo ESPRIT, enregistre sous le nom :
       esprit-logo.png    (ou .jpg / .jpeg / .pdf)

Je n'ai pas d'outil pour extraire automatiquement les images que vous avez collees
dans la conversation vers un fichier sur le disque : il faut les enregistrer vous-meme
ici (clic droit sur l'image -> "Enregistrer l'image sous...") avec exactement l'un des
noms ci-dessus.

Tant que ces fichiers sont absents, le document compile tout de meme : la page de garde
affiche un encadre "[Logo BIAT IT]" / "[Logo ESPRIT]" a la place, pour ne jamais bloquer
la compilation.
